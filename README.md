# ssnxd's configs

Dotfiles with theme-aware configuration for Neovim, Ghostty, and Tmux.

## Quick Start

```bash
# Clone the repository
git clone <your-repo-url> ~/code/config
cd ~/code/config

# Run setup (dark theme, config only)
./setup.sh

# Or with options
./setup.sh --theme light           # Use light theme
./setup.sh --install-deps          # Also install Homebrew dependencies
./setup.sh --reload-tmux           # Kill and restart tmux server
./setup.sh --help                  # Show all options
```
